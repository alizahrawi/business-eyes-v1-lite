# Business Eyes Architecture

This folder contains the BPMN-like workflow for Business Eyes v1 Lite.

## Files

- `business-eyes-workflow.png` — high-resolution image for GitHub, presentations, and social content
- `business-eyes-workflow.svg` — scalable vector version
- `business-eyes-workflow.mmd` — editable Mermaid source

## Workflow scope

The diagram documents three connected processes:

1. **Onboarding and access control** — Telegram registration, the five-day trial, Mini App launch, signed identity validation, and subscription checks.
2. **AI report generation** — Persian activity input, report-style selection, Hugging Face inference, deterministic fallback, editing, and sharing.
3. **Wallet and subscription** — Telegram Stars invoices, pre-checkout validation, wallet crediting, balance checks, and 30-day or 90-day subscription activation.

## Editing the workflow

Open `business-eyes-workflow.mmd` in any Mermaid-compatible editor. GitHub also renders Mermaid diagrams directly inside Markdown code blocks.
